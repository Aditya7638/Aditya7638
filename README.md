## 🚀 Things I've Built

### 🤖 AI Interview Simulator

Interview preparation can become messy — different websites for questions,
practice, feedback and tracking progress.

I built this project to bring those pieces together into one place where students
can practice interviews in a more structured way.

The platform focuses on **question generation, answer evaluation and feedback**,
giving users a way to practice and understand where they can improve.

**Tech:** Python · FastAPI · Streamlit · PostgreSQL · LLMs

🔗 [View Project Repository](https://github.com/Aditya7638/AI-Interview-Simulator-App)

---

### 🧘 YogKriya

Knowing yoga exercises is easy.

Building a consistent routine is the difficult part.

I built **YogKriya** around that problem — helping users discover exercises,
organize them into routines and schedule when they want to practice.

The idea is to make yoga feel less like something you *plan to do someday*
and more like something that actually becomes part of your routine.

**Choose → Plan → Schedule → Practice → Stay Consistent**

**Tech:** React · TypeScript · FastAPI

🔗 [View Project Repository](https://github.com/Aditya7638/Yogkriya)
[Deployed Link of this App](https://yogkriya.vercel.app)

---

### 🩻 Pneumonia Detection System

Chest X-rays are an important tool in detecting respiratory conditions,
but examining medical images requires time, experience and careful analysis.

I built this project to explore how a computer vision system could assist
with the initial classification of chest X-ray images.

The system takes a chest X-ray as input and classifies it as **Normal**
or **Pneumonia**.

Building it gave me practical experience with **image preprocessing,
model training, evaluation and deploying a trained model into an application**.

**Tech:** Python · PyTorch · Computer Vision · Streamlit

🔗 [View Project Repository](https://github.com/Aditya7638/ai-xray-pneumonia-detecto)
